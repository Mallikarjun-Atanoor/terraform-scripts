📦 S3 + CloudFront Static Website (Terraform)

This project provisions a secure, production-ready static website using Amazon S3 and CloudFront, fully automated with Terraform.

🚀 What this project does

Creates an S3 bucket to store static website files

Blocks public access to S3

Uses CloudFront as a CDN for fast global delivery

Secures S3 access using Origin Access Control (OAC)

Uploads website files (HTML / CSS / JS) via Terraform

🧱 AWS Services Used

Amazon S3

Amazon CloudFront

IAM (bucket policy)
