📊 AWS S3 + Athena Data Lake
🔍 Overview
✔ Store data in S3  
✔ Query data using SQL (Athena)  
✔ No database needed  
✔ Fully serverless  


🏗️ How it works
S3 (files)
   ↓
Glue (schema)
   ↓
Athena (SQL query)
   ↓
S3 (results)


⚙️ What you can do
✔ Run SQL on CSV files  
✔ Filter, clean, analyze data  
✔ Get results instantly


🔄 Flow
Upload CSV → S3  
      ↓  
Query in Athena  
      ↓  
Result stored in S3
